## 

## \# Autonomous Rover using ROS2 \& SLAM

###### 

###### \## Overview

This project is part of a team-based autonomous robotics system developed for environment navigation and task execution. The rover uses ROS2, LiDAR, and a 3D depth camera for mapping and navigation. My contribution focused on rover behaviour programming in Python and boom gate detection/control logic.

## 

###### \## Project Objectives

\- Enable autonomous rover navigation in a mapped environment

\- Define rover behaviour during task execution

\- Detect rover arrival and trigger an automated boom gate

\- Support system-level integration for autonomous operation

## 

###### \## My Contribution

My specific contribution to this project included:

\- Developing Python-based rover behaviour logic

\- Defining what the rover should do and when it should do it during the task sequence

\- Implementing boom gate detection and control logic

\- Testing integration between rover behaviour and gate operation

\- Preparing project documentation and report content

## 

###### \## Repository Contents

\- `src/` - Python scripts related to rover behaviour logic

\- `boom\_gate/` - boom gate detection and control logic

\- `report/` - project report or submitted documentation

## 

###### \## How It Works

1\. The rover navigates within the mapped environment.

2\. Python behaviour logic determines rover actions during task execution.

3\. When the rover reaches the boom gate zone, the gate logic is triggered.

4\. The gate opens/closes based on rover position and detection logic.
