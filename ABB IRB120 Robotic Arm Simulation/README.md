## \# ABB IRB120 Robotic Arm Simulation

## 

###### \## Overview

This project involved simulation and programming of an ABB IRB120 robotic arm using ABB RobotStudio. The task focused on configuring the robot tool and generating a path that enabled the robot to write a name on paper.

## 

###### \## Project Objectives

\- Simulate an ABB IRB120 robot in RobotStudio

\- Configure tool center point (TCP)

\- Develop robot path logic for writing tasks

\- Validate motion accuracy in a simulated environment

## 

###### \## Technologies Used

\- ABB RobotStudio

\- ABB IRB120

\- TCP Configuration

\- Robot Path Programming

###### \## How It Works

1\. The robot model is loaded into RobotStudio.

2\. The tool and TCP are configured for the writing task.

3\. Path points are defined for letter movement.

4\. The robot executes the writing motion in simulation.

5\. The trajectory is reviewed and refined for accuracy.
